## ⭐⭐⭐ 필수 — 핵심 기능 (이게 안 되면 프로젝트 성립 X)

### 환경 셋업

- [ ] Ubuntu 22.04 + ROS 2 Humble 설치
- [ ] Gazebo + RViz + URDF 동작 확인 (TurtleBot3 기본 시뮬 실행)
- [ ] Dobot RoboDK 설치 및 Dobot 모델 로드
- [ ] YOLOv8 환경 셋업 (PyTorch + CUDA, GPU 인식 확인)
- [ ] Django 프로젝트 생성 + Django REST Framework 셋업
- [ ] MySQL 연결 + `.env` 환경변수 관리
- [ ] Vue 프로젝트 생성 (Vue Router, Axios 설치)
- [ ] Git 저장소 + 브랜치 전략 정하기

### 데이터베이스 모델

- [ ] `items` 테이블 — 분실물 (카테고리, 묘사, 사진 경로, 슬롯 ID, 상태, 만료일)
- [ ] `reports` 테이블 — 신고 (이메일·이름, 카테고리·묘사·시간·장소, 매칭 ID, 확인코드, 상태)
- [ ] `warehouse_slots` 테이블 — 창고 슬롯 (좌표, 점유 여부, 슬롯 타입)
- [ ] `robot_tasks` 테이블 — 로봇 작업 큐 (로봇 종류, 작업 타입, 페이로드, 상태)
- [ ] 마이그레이션 작성 + 시드 데이터 (창고 슬롯 초기화)

### 비전 시스템

- [ ] 분실물 카테고리 정의 (지갑, 휴대폰, 열쇠, 가방, 우산, 이어폰, 안경 등 7~10종)
- [ ] 분실물 사진 데이터셋 수집 (카테고리당 100~200장, 다양한 각도)
- [ ] Roboflow에서 데이터셋 라벨링 (bounding box)
- [ ] Roboflow에서 train/val 분리 후 YOLOv8 학습
- [ ] 학습된 모델 export (`.pt` 파일) + Python에서 로딩
- [ ] OpenCV 흰 배경 segmentation (HSV 임계값 또는 GrabCut)
- [ ] 카메라 캘리브레이션 (체커보드 + `calibrateCamera`로 내부/외부 파라미터)
- [ ] 픽셀 좌표 → Dobot 좌표 변환 함수 (homography 행렬)
- [ ] IR 센서 트리거 → 사진 촬영 → 분류 → DB 저장 파이프라인 통합

### Dobot 제어

- [ ] Dobot Python SDK 설치 + 연결 테스트 (TCP 29999/30003)
- [ ] Dobot 명령 래퍼 작성 (move_to, gripper_on/off, get_pose 등)
- [ ] Dobot을 ROS 2 노드로 래핑 (액션 서버 형태)
- [ ] 그리퍼 어태치먼트 Onshape 설계 (흡착 + 평행 옵션)
- [ ] 그리퍼 STL export + 3D 프린팅
- [ ] 그리퍼 제어 (흡착 ON/OFF, 그립 폭 조절)
- [ ] RoboDK 시뮬에서 작업대~창고~폐기함 좌표 등록
- [ ] **시나리오 1 시뮬**: 작업대 위 물건 피킹 → 빈 창고 슬롯에 적재
- [ ] **시나리오 2 시뮬**: 신고 매칭 시 창고 슬롯에서 꺼냄 → TurtleBot 적재대 위에 내려놓기

### TurtleBot 제어

- [ ] TurtleBot 부팅 + ROS 2 통신 확인
- [ ] Gazebo에 가상 분실물 센터 맵 모델링 (벽, 창고 위치, 반환 창구)

- [ ] Nav2 파라미터 튜닝 (속도, 회전 반경, 장애물 회피 거리)
- [ ] `/turtlebot/navigate_to_pose` 액션 인터페이스 노출

### 통신 인프라

- [ ] Django에서 rosbridge에 연결하는 클라이언트 구현 (roslibpy 등)

### 백엔드 핵심 API
